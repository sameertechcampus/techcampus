# Staff Leave Planner

Excel workbook and generator for a yearly staff leave planner.

The workbook supports:

- editable planner year
- 20 staff members
- leave types: Annual Leave, Sick Leave, Time of Request, Training
- requests tracking
- staff summary
- management dashboard

Main workbook:

- `staff_yearly_leave_2026_management_ready.xlsx`

Generator:

- `generate_clean_leave_workbook.py`
